# 💻 C Programming Journey

Welcome to my C programming repository! 👋

This repository contains the C programs I write while learning the fundamentals of the C programming language. It serves as my personal coding journal where I practice concepts, solve problems, and improve my programming skills one step at a time.

My goal is to build a strong foundation in programming by mastering C before moving on to more advanced topics and languages.

* Strings

* File Handling

* Practice Problems

## 🛠️ Compiler

These programs are written in standard C and can be compiled using:

* GCC
* Clang
* Code::Blocks
* Visual Studio Code (with a C compiler installed)

Example:

```bash
gcc filename.c -o program
./program
```
